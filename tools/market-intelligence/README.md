# Apify Market Intelligence Pilot

Issue: [#665](https://github.com/aokcuoglu/bakimx/issues/665). This is a standalone marketing research utility. It has no application runtime, Prisma, scheduler, or production dependency.

## Commands

- `bun run market:intel:preflight`: checks `APIFY_API_TOKEN`, connectivity, monthly usage, and remaining credit. Starts no Actor.
- `bun run market:intel:competitors`: crawls BakımX, PADOK/Hayat Yazılım, ServisData, and Kursoft with the official Website Content Crawler, Cheerio mode, at most 8 pages and depth 2 per site.
- `bun run market:intel:analyze`: rebuilds JSON, CSV, and Markdown from local normalized datasets and `curation.json`; makes no network request.
- `bun run market:intel:phase2`: performs a separate preflight and reuses completed datasets. Phase 2 includes one bounded Google Search run, one Meta keyword run for PADOK, ServisData, and Kursoft, and one targeted Meta page URL follow-up for Hayat Yazılım and Kursoft (at most 10 ads per URL). The combined Phase 2 budget remains $0.50; the Meta runs have $0.20 and $0.13 hard caps. Existing runs are never repeated automatically.
- `bun run market:intel:phase2:analyze`: rebuilds the Phase 2 report and local CSV from the existing ignored dataset; makes no network request.

Set `APIFY_API_TOKEN` in an ignored local env file or process environment. Never paste it into a command argument. Optional `APIFY_MONTHLY_CREDIT_USD` and `APIFY_PILOT_BUDGET_USD` default to 5 and 0.50, with hard ceilings of those values. The live command checks current monthly usage and settled Actor spend before each new Actor run; it stops at $4.50 monthly usage or $0.50 pilot spend. Phase 1 crawler runs each have a $0.12 Apify charge cap; the Phase 2 Google run has a $0.50 cap, and the Meta runs have $0.20 and $0.13 caps within the shared Phase 2 budget. Existing local datasets and run IDs are reused so an interrupted command does not start a duplicate run. An Actor failure is recorded and is never retried automatically.

Raw normalized pages and the run manifest are stored under ignored `tmp/market-intelligence/`. Only curated, source-linked findings and aggregate output under `tools/market-intelligence/output/` are intended for review. Edit `curation.json` after reading the raw pages, then rerun `market:intel:analyze`. Every non-unverified claim must cite a collected URL; the report generator enforces this.

The Actor fields were checked against the [official input schema](https://apify.com/apify/website-content-crawler/input-schema). The Actor requires proxy configuration; an empty group list uses the default [datacenter proxy](https://docs.apify.com/proxy/datacenter-proxy). Cost and API behavior were checked against [monthly usage](https://docs.apify.com/api/v2/users-me-usage-monthly-get), [Run Actor](https://docs.apify.com/api/v2/actors-runs-post), and [Get run](https://docs.apify.com/api/v2/actor-run-get). The Actor runs do not use AI summarization, browser rendering, residential proxy, or file downloads.

Phase 2 uses the [official Google Search Actor input schema](https://apify.com/apify/google-search-scraper/input-schema): one page per query, Turkish country/language, no paid ads or AI/content/lead add-ons, no HTML snapshots. Meta uses the [official Meta Actor input schema](https://apify.com/apify/facebook-ads-scraper/input-schema): three Turkish Ad Library keyword URLs followed by two identified page URLs, at most 10 ads per URL, and no extra detail or e-commerce enrichment. Both Actor inputs are validated with Apify before a run, and the current minimum `maxTotalChargeUsd` is read from Actor pricing metadata. Normalized SERP/ad JSON, query summaries, CSV, and run manifest are ignored under `tmp/market-intelligence/phase2/`; the Markdown report is under `output/`. A zero-ad query summary only describes that query's response; it is not proof that the advertiser has no ads. The [Meta Actor developer says it enforces residential proxies internally](https://apify.com/apify/facebook-ads-scraper/issues/residential-proxy-fo-YD0alNTBZG9sg23yG); the user explicitly authorized lifting the residential proxy restriction for these Phase 2 Meta runs. The Phase 1 crawler remains Cheerio with datacenter proxy.
